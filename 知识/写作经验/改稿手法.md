# 改稿手法（跨篇复用）

> 这是从已发表文章里沉淀出来的**通用改稿手法**，不属于某一篇。原文在 `选题框架 §五`（炉甘石篇），
> 该节随文章发表归档删除后迁到这里——**手法留着，下次改稿直接调**。
>
> **写初稿前必读（2026-10-12 起）**：本页最后两节是「作者的语气规范」——〈作者的改稿规律〉（15 条，来自四对
> 初稿/定稿逐字 diff）＋〈语料级分析〉（12 条，来自 41 篇首发＋4 篇定稿）。**写任何新初稿时先照着它写**，
> 别等改稿才用——2026-10-12 两版初稿被否（"写得太硬、AI 味太重、没什么感情"）就是这个原因。
>
> **改稿/定稿前另必查**：[[排版规则]] §十「平台敏感词」（死／群／礼物／首…）——命中就换同义口语说法。

### 5.5 用户重写版 + 本轮六处优化（2026-09-24，可复用的改稿手法）

用户自己重写了一遍，Agent 在其基础上做了六处优化。**手法留着，下次改稿直接调**：

1. **开篇倒装——先给后果，再补前提。** 原稿是"我离开了一小会 → 回来看到…"；改成
   "**一整瓶炉甘石洗剂，全倒在了床上。** → 我就离开了一小会。 → 等回来时，看到的是——"。
   同一件事，顺序一换，第一句就是最重的事实。（`plan §3.1` 句式 1：具体事件＋数字锚点＋反转）
2. **四个分节给上小标题。** 原稿只有"一、二、三、四"。小标题在手机上是导航，也是"下一节有东西"的承诺，
   是降跳出最直接的手段。全部用她自己的原话取：情绪马上就要出口的那一瞬间 ／ "这些得你自己收拾" ／
   她扔了晾衣杆，又扔了抹布 ／ 她第一次摸到错误的重量。
3. **长段拆成短段**（一句一行、段间空行）。别等排版那步再拆，**写的时候就拆**——这是手机上的存活率。
4. **把感染力最强的那句从总结挪回现场。** "腿酸／手酸是真的"原来只在第四节复盘里；现在第三节
   （她抱怨手酸、扔抹布那一刻）加一句"**因为那份手酸，就是她今晚要拿到的东西**"，总结里留一半。
   **感染力落在现场，不落在总结。**
5. **题眼和落点各自独立成段并加粗。**"妈妈怎么总生气"独立成一段（它最容易被记住）；
   "我把原属于她的重量搬到了自己身上"独立成段并加粗（它是全篇落点）。
6. **数字统一 ＋ 自问自答收一处。**"2 分钟"→"两分钟"（`排版规则 §七` 全文统一）；
   四处自问自答收成三处（"那怎么才能让她知道"与"那我想要的是什么"是同一问题的两面）。

**按建议删掉的（本轮最大的改动）**：原稿结尾三句——"长大，意味着承担。自主，联系着责任。原来，
从孩童时开始，我们就已经在学习这一点了。而做了父母之后，这个简单的道理越发明晰。"
**前面全篇是"我"，这三句滑成了"我们／原来"，从一个人的发现变成了一篇道理**
（`痛点地图 E`：写处境不写方法论）。现在收在"我把重量搬到了自己身上"，那已经是最高点。

**两处按用户要求**：① **"七七"是小名，用户同意写出来**（此前所有文章都只写"女儿"）；
② **时间保持宽泛**，只写"直到现在"，不给具体月数。

---

**用法**：作者自己重写完的那一版优先，Agent 的任务是**在它上面找问题**，不是把它改回自己的版本
（见 `log.md` 2026-09-24 起的多轮记录）。上面六条按"开篇→分节→分段→感染力→题眼→数字"的顺序过一遍，
就是一次完整的改稿动作。


## 作者的改稿规律（2026-10-12 从四对「初稿（Agent版）→ 定稿（作者重写）」逐字 diff 提取）

**证据**：`个人原创/已发布/后续发表文章（含初稿定稿）/` 下四对。炉甘石那对最典型：初稿 7549B → 定稿 6179B，
**她删掉 18%**，但内容更多——删的全是我的解释，加的全是她的实况。

### 她一删掉的（我的"AI 味"主要来自这些）

1. **元叙述**："但这篇想讲的不是……""我想说说我自己""先说清楚一件事" → 全删
2. **概念分类与定义句**："不知道和不在乎是两件事。不在乎是态度问题……" → 删；同一个意思改成她的自问句
   （"——那有没有可能，她不是不在乎，而是不明白？"）
3. **成串的抽象结论**（"怕是最短的那条路，也是唯一一条我不在场它就会断掉的路"）→ 删
4. **直接对读者的反问、"与每一个……共勉"式落款** → 两篇里一个不留。（她保留的是"有人可能会说：这不还是得有条件吗？"
   这种**虚构读者的一句质疑**，紧接着"我不认同"）
5. **"我比那个网友好一些"这类自我评价/比较** → 删

### 她二加上的（她的感情从这里来）

6. **自问自答的心理链（招牌）**："我在心里问自己：为什么这么生气，是因为这满地狼藉吗？回答是：是，但不全是。"
   "继续想：那我想要的是什么？"
7. **过程细节／可操作的动作链**：一句"这些得你自己收拾"展开成 4 条家务清单＋"她拿晾衣杆没成功、气得扔在地上"
   ＋"她自己打水、拧抹布"＋"我忍住自己上手的冲动"
8. **身体感受当支点**："蹲在地上捡棉签的腿酸是真的，拧毛巾擦地的手酸是真的，一趟趟跑来跑去的累是真的"
9. **直白的情绪词**："我的火一下就上来了。""可我还是难过。""我什么都没说，转头回到了客厅。"——不绕、不修饰
10. **逗号切出的停顿（招牌节奏）**："三岁左右的孩子，手，已经够得着窗台了，但脑袋，还够不着道理。"
11. **小标题用画面／动作／原话**，不用名词标签："情绪马上就要出口的那一瞬间""'这些得你自己收拾'"
    "她扔了晾衣杆，又扔了抹布""她头一次摸到错误的重量"
12. **对孩子的直接称呼进对话**："七七，你不应该这么玩。"
13. **口语连接词与语气**：就／才／还／反正／其实／慢慢／只好；啊／呢／嗯／……；感叹号敢用；"的/地"口语写法不纠
14. **别人的一段话当开场、然后落到自己**："看到一位网友说……看完，我也想起了一些跟节日有关的记忆。"
15. **落点收在"我要学什么"或一个实物/动作的余味**："而我要学的，是放手不再替她背。""嗯，明年中秋，她大概能做更多了。"

### 总纲

**我的初稿靠"分析"推进，她的定稿靠"实况＋自问＋身体感受"推进。** 写新初稿照这 15 条自检，
尤其每段问一句：这句是在分析，还是在过日子。


## 语料级分析：全量已发表文章的共性（2026-10-12，41 篇首发 + 4 篇定稿，约 10 万字）

上一条是"改稿差异"，这一条是"她本身长什么样"。硬数据：**问号 224 / 感叹号 143 / 省略号 106 / 破折号 163**；
人称 **我 1646 / 她 604 / 我们 454 / 你 438**。小词频次：只是 68、总 82、一点 43、终于 33、其实 32、忽然 29、
突然 23、也许 23、于是 22、慢慢 14、反正 4。

1. **靠自问推进，不靠呐喊**：问号是感叹号的 1.5 倍，自问自答/心理问答链是她推进文章的主力。
2. **最高频骨架＝"不是A，而是B"**："不是因为生活在一个和平的世界，而是因为生活在一个和平的国家。"（《我们并非生而和平》）
3. **"原来，…"式顿悟收束（全语料出现极多）**："原来，所有的'狠心'，都是母亲为孩子穿上的铠甲。"（《送女儿上幼儿园》）
4. **破折号＝揭示本质、把判断钉死**："她蹬鼻子上脸——没有第三种结果。"（定稿_看到三岁女儿倒满床的炉甘石）
5. **凡自造概念，必加引号**："我执""硬筹码""微型冬天""堡垒"——引号是她的新词标记。
6. **身体感受代替情绪形容词（她最动情的手法）**："头皮仿佛传来一阵真实的隐痛。""三月的阳光照在她半白而稀疏的头发上，
   刺得我眼睛发胀。""脚后跟磨得血肉模糊。"
7. **开头 5 式**：①动作/物件瞬间切入（"一整瓶炉甘石洗剂，全被我女儿倒在了床上。"）②时间数据锚点（"昨晚睡前，
   我和先生聊到凌晨两点多。"）③反向金句（"人际关系里最大的谎言就是：只要我退让，就能换来和平。"）
   ④引用别人的话（"看到一位网友说，她小时候，家里从来不过节。"）⑤物件气味（"外出遛娃时，无意中发现路边的柏树结出了柏子。"）
8. **结尾 5 式**：①"愿我们…"祝愿 ②回环呼应开头（"嗯，明年中秋，她大概能做更多了。"）③短句留白（"这就够了。"）
   ④行动号召＋互动（"点个「在看」，愿我们都能成为家人最稳固的那座山。"）⑤自我和解式叮嘱（"允许她慢慢长大，也允许我们偶尔犯傻。"）
9. **她特有的句式**："与其A，不如B"／三段"当…时"排比／"从A到B，再到C"／"我又何尝不是…"／"……才明白"／
   一个动词拆成两个近义并列（"梳理，重塑"）／直接呼唤式收尾（"谢谢你，我的小姑娘。"）
10. **并列多用逗号、少用顿号**："我就唱歌，跳舞，弹琴，读书"。
11. **对孩子的姿态是俯身**（蹲下来、压低声音、柔声、郑重地）；**对父母是愧疚与体谅**；**对自己是温柔劝慰**。
12. **有些篇目用数字化清单**："回家后我做了三件事""三阶自救功法"。

**写新初稿的一句话总纲**：情绪要靠**身体和动作的证据**送到读者面前，让读者自己完成感动——不写"我很感动"，
写"鼻子一酸""眼睛发胀""张了张嘴又闭上"；不写"我顿悟了"，写"原来，…"。


## 第五对：牵牛花篇（2026-10-13，作者亲改版 vs Agent 初稿 1368 字 → 作者版 1380 字）

**A. 她在结构上做的三件事**
1. **并节**：把 Agent 的"开篇（物候＋寻宝＋三句话）"整块**并进第一节**（跟花对话之后直接接"继续往前跑，边走边欣赏小区的秋景"）→ 第一节变成"对话＋一路寻宝"，一个连贯的上午。
2. **删掉开篇的总结句**（Agent："她不认识这些东西，可她是真的高兴…也是她快乐的来源"）→ 改成画面："她像是在进行一场寻宝之旅，不时回来跟我分享她的收获…**如获至宝，喜笑颜开**"。
3. **砍掉 Agent 加的落叶来由**（她先发现／我提议作画／她挑叶子／她怕弄丢非要放包里，Agent 写了整段）→ 她收成一句"后来，我们满载而归，捡了些漂亮的落叶回家，准备做一幅叶贴画"。
   注意：这跟"加过程细节"不矛盾——**她留的是自己的实况，砍的是 Agent 渲染出来的过程**（给我们的启示：细节只有她自己给过的，才值得写长）。

**B. 她把 Agent 的"概括"逐句换成"动作/原话"**
| Agent 初稿（概括） | 作者版（动作/原话） |
|---|---|
| 我蹲在她旁边（对话收尾：然后她就跑开了） | **"哦！我要走啦！再见。"** ＋ **跟小花摆摆手**才跑开 |
| 指着月季果问我"这是什么，能吃吗？"（到此为止） | 补全：我答"这是月季花的果实，不能吃" → **"哦……"她尾音下垂**，好似有些失望，但很快又高兴起来 |
| 蚯蚓（就把它重新送回路边花坛的土里） | **用两根小树枝夹起它**，送到泥土里，**跟它说："不用谢。"** |
| 蚂蚁（用小树枝帮它们把食物挪到洞口） | 补**长期关系**：初时它们害怕四散奔逃，**后来这样的事多了，它们也不逃了，欣然接受了我的善意** |
| 大人做起来会先怕别人看傻子的眼神 | 补**具体演示**："我会先看看周边有没有人。没有的话…有人的话，就只能拍张照了。／**毕竟，我已经长成了大人。**"（一句独立成段） |
| （无过渡） | 二节开头用身体过渡："**暖暖的阳光让身体热了起来**，我被她的快乐感染，想起了一些久远的记忆——" |

**C. 她加了全篇最重的一层（Agent 完全没写到）**
- **"我的开心甚至是双倍的，因为，深藏心底的那个小女孩很开心，做了妈妈的大女孩也很开心。"**
  —— Agent 写的是"我也在哄我自己"（辩解式），**她把它升级成"两个我都开心"**（礼物式）。这是全篇真正的落点句。
- 凤仙花结尾加了 **"她的眼睛瞬间冒出光来，惊喜极了。／跟我头一次发现这种植物时一模一样。"**
  —— Agent 写"我小时候也这么玩"（陈述），她改成**照镜子**（她的惊喜＝我当年的惊喜）。

**D. 语言替换（小，但准）**
- "我蹲在她旁边" → **"我一乐，蹲在那朵花旁边"**（加情绪）；"她说" → **"她对花说"**（视角更准，因为那句话是说给花的）；"我说" → **"我继续代花发言"**（身份更清楚）
- "你会先怕别人看傻子的眼神" → **"这些事，孩子做起来没有负担，但大人做起来，会首先担心别人看傻子的眼神"**（对照更硬）
- 开篇："那天上午天很好。浅蓝的，看着很高，阳光暖，但不烫。" → **"入秋之后，阳光变得温暖而不炽烈，天空蓝而高远。"**（她的书面度比 Agent 更高一档——**别默认她只要口语**）

**E. 给下一次初稿的四条**
1. **她的"金句"要让位给她的"双倍"**：Agent 容易停在"我也很想要／我也在哄自己"这种自我辩解上；她的落点是**把好处分给两个自己**（或分给孩子）。
2. **凡是 Agent 自己渲染出来的过程，默认砍成一句**；只有她口述过的动作才写长。
3. **概括句一律换成"有个具体的人在旁边看着"的动作**（有人就拍照、等它重新出来、跟它说不用谢）。
4. **书面度可以比 Agent 的默认再高一档**（"温暖而不炽烈""如获至宝，喜笑颜开""尾音下垂"都是她的词）。


## 第六对：牵牛花篇 作者再改版（2026-10-13，1349 字）

作者在"排布优化版"（= 她的稿 + Agent 只动段序/空行/断句）之上再改，改法有四条值得记住：

1. **她敢整段删景物描写**：Agent 把中段的"海棠树的果子半黄半红…忍冬深绿的叶子间…"后置处理，她**整段删掉**，
   连"边走边欣赏小区的秋景"一起收成"我也赶紧站起来跟上"。理由：**开篇那句"入秋之后，阳光变得温暖而不炽烈"
   已经把秋天给过读者了，中段再铺一次是重复**；而且那段是唯一"有景无事"的段落，正是完读率最容易掉的地方。
2. **她补关联词把逻辑补齐**（很小，但准）："想起了一些久远的记忆" → "**也**想起了一些久远的记忆"；
   "现在还没动手…但没关系" → "**虽然**现在还没动手…但没关系"。→ 给 Agent 的启示：**"虽然…但…""也"这类虚词缺了就是硬伤，
   我写的稿要自查一遍逻辑连接词。**
3. **她改口语节奏**："她像是" → "她**像**"；"不**时**回来" → "**时不时**跑回来"。
4. **她把结尾的"共鸣"扩了一层**：Agent 的草案是"如果你也曾在孩子面前偷偷做回小孩，那这篇写的也是你"（= 你也是这种人）；
   她改成"如果你也曾在孩子面前偷偷做过小孩，**想起过儿时的自己**，那这篇也写给你，**写给我们未曾泯灭的童心**"
   —— 多了一重"**你也有那段记忆**"，把认领面从"同类"扩到"所有人"。**但她这一版唯一被我提意见的地方也是这里**：
   "未曾泯灭的童心"比前半句抽象一号，是全篇唯一"抬头对大家说话"的句子，略带散文腔（作者可自行取舍）。

**第六对补记（2026-10-13）**：作者把结尾"写给我们**未曾泯灭的童心**"改成"写给我们内心那个**喜欢与自然对话的孩子**"——
**结尾不要用成语式的抽象总结，要用"一个具体的人＋他在做的事"**；而且那个人最好就是正文里出现过的自己（本篇的蜗牛、蚯蚓、蚂蚁、蝉、跟一朵花说话）。


## 第七对：柿子树篇（2026-10-15 作者三轮亲改：1058 → 1235 → 1188 字）

1. **重写之后，小标题必须重新从新内容的落点里拟**——作者原话："不要为了小标题而写内容，这是本末倒置了。"

   小标题必须让位，不能重复。
2. **结尾别叠同义道理。** 她三节末尾原来连着三句同义的（"事物没有变，是人的心态"／"我们总在期待远方"／"与其把心放在远方，

3. **收束方向她选了"向前看"**（"我有点期待冬天了。那时，叶子该落尽了…若覆上一层薄雪，就更有情致了"），

## 全量八对总结（2026-11-02，新增六对：炉甘石／认真过节／近代史／婚恋／这个字／27岁到31岁）

### 总纲修正（最重要的一条）

旧总纲"AI 靠分析，她靠实况＋自问＋身体感受"仍成立，但八对数据的完整表述是：

**她删的不是"抽象"，是"不真"。** AI 替她想的结论、AI 编的画面、AI 的论证腔，一律删；但同样类型的句子她自己写就留——八对里她自己写过共勉落款（"——与每一个决定先把自己建设完整的你，共勉。"）、对读者反问（"也许你会问…""回头看看他们当年走过的路吧"）、抽象金句（"人生才有万般滋味"）、自我评价（"虽然能力有限，文字表达的远不如我真正所想的"）。**改稿判据：这句是她的真判断/真记忆，还是 AI 代笔。** 以后写初稿别用"她的风格"当挡箭牌写抽象句——抽象句只能她来写。

### 新规律

1. **事实校准永远先于修辞。** 每对 diff 她最先改的是事实：三年半→约四年半（27岁篇）、读书→看剧《觉醒年代》（近代史篇）、先生→付先生、到北京之后→来京一年半工作近七年、次数 2→1（炉甘石篇）、地点→"北京"。**初稿里每个数字、称谓、触发源她都核。**
2. **AI 的加粗一处不留。** 八对里初稿所有 ** 加粗在定稿中消失（发表格式纯文本＋她不用加粗强调）。**以后初稿不写加粗。**
3. **"先抑后扬"否定式结构必拆。** "不是因为它流量好，是因为…""不是因为她说错了，是因为…"这种 AI 论证腔，她一律拆成一句直说。
4. **AI 替读者做心理分析必删。** "一个从小没被好好爱过的人，最怕的从来不是改变…"（婚恋篇）整段删，换成"我完全理解她。"——她只写自己，不诊断别人。
5. **AI 编的画面清单必删，换她的真记忆。** 婚恋篇 AI 写"写女儿在幼儿园门口不肯进去的那半个小时"三连未来画面→删；认真过节 AI 写"你让她做花灯，她会把纸撕了"的生动排比→删，换她真童年"馋嘴小孩趁大人不注意，溜进厨房偷吃…"。**画面再好，不是她的真记忆就不要。**
6. **AI 的自问 vs 她的自问有判据。** AI 自问后面接解释（"然后呢？然后我什么也没做"——炉甘石/近代史里被删），她自问后面接行为或决定（"那我想要的是什么？回答是：让她自己承担后果"）。**以后写自问，后面必须跟行为，不跟解释。**
7. **AI 的假设推演她不写。** "如果早几年遇到，会怎样？大概不行"整节删（27岁篇）。她写事实，不写虚拟论证。
8. **增删方向由内容缺口决定。** 八对：4 篇压缩（炉甘石 -19%、柿子树 -6%、27岁 -11%、牵牛花 -2%）、1 篇持平（这个字 -1%）、3 篇扩充（近代史 +39%、认真过节 +12%、婚恋 +3%）。缺料就补（近代史补触发源与史料、认真过节补童年实况），不是"她总在压缩"。
9. **小标题从正文里拔短语。** 柿子树篇 AI 句子"早就是秋天的背景了"正文删掉、"秋天的背景"拔成小标题；27岁篇"回到大地的怀抱"同法。**小标题素材必须是正文已有的她的原话短语。**
10. **大标题意象必须正文兑现。** 27岁篇大标题"盆栽回大地"是她的重写补进正文的——标题认领的意象，初稿正文必须写出来。
11. **对话按角色分向改。** 牵牛花篇：大人代言越改越简（"我大名叫牵牛花"→"我叫牵牛花"），孩子越改越活（加"哦！我要走啦！再见"+摆手动作）。
12. **她的抽象段换论证工具。** 柿子树篇"习惯"段：AI 用对比煽情（"它不像失去。失去会疼"）→删；她写"就像是时间演变的具象化，不偏不倚的…"比喻式下定义。**她不是不写抽象段，是不写 AI 式对比论证。**
13. **她认领 AI 句子的标准：留"我"的感受句，删分析/辩解/论证句。** 牵牛花篇"反正等贴上去的那天，先被哄开心的，还是我"原字保留；"可那几分钟里让我快乐的…是那几分钟里，没有一件事需要做对"连上下文删。
14. **意象提炼放大。** 炉甘石篇"重量"从正文散句（"它有多重，就得她自己扛到多重"）升级为末节小标题"她头一次摸到错误的重量"＋反向落到妈妈（"是我总把原属于她的重量搬到自己身上"）。**她抓初稿里的一个意象升级为全篇落点——初稿要埋可升级的意象。**
15. **结尾两分。** 育儿现场型收"我要学什么"（炉甘石"而我要学的，是放手不再替她背"）；感悟型允许抽象总结＋互动提问收（27岁"万般滋味"+"一起聊聊吧"）。**按篇目调性选收法。**
16. **悬念留白标题。** 这个字篇 AI 结论式标题"父母从没对我说过爱，女儿却天天说给我听"→她换成"这个字，我说给了女儿，却从没说给我妈"。标题留白（与标题规则页一致）。

### 写初稿实操清单（照做）

1. 不写加粗；不写"先抑后扬"；不写假设推演；不替读者做心理分析。
2. 每个数字、称谓、地点、触发源写前先问她要，写不出的留空标注，绝不编。
3. 自问后必接行为/决定；画面只用她的真记忆，缺料就留白问她要。
4. 正文埋 1-2 个可升级的意象（物品/重量/光），结尾按篇目调性选"我要学什么"或抽象+互动。
5. 小标题候选直接用正文她的原话短语；标题意象写进正文。
6. 写完自检：这句是"她的真判断"还是"我替她想"——后者删。
