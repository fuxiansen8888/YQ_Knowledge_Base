## 六、即梦实操六条

1. **每条都从通用风格前缀起头**，别省。
2. **比例在图界面选，提示词里也写一遍**，双保险。
3. **封面图不加字**（2026-10-22 作者定）：标题在封面图下方显示，图内不叠字，**也不用为叠字留白**——画面可以填满。中文交给 AI 照样会写成错字，这条仍然有效。
4. **人物画正常清晰的五官**（2026-11-02 作者改），表情温柔自然——不再用剪影、背影或模糊脸规避；插画里是 AI 虚构面孔，不涉及真人长相。
5. **水彩风格出图波动大**：同一条提示词连出 4 张再挑，别出一张不满意就改词。
6. **插图位置**：每节正文结束之后、下一条 `---` 之前；本篇五张图都不需要图注。

## 七、实例二：炉甘石那篇

**文章**：《看到三岁女儿倒满床的炉甘石，我转头去了客厅》（定稿，2026-09-24）
**规格同 §一**：封面 21:9；插图 4:3，每节一张（4 张）。§二 的风格前缀、§三 的负面词照用。

### ★ 核心视觉策略：把狼藉画成初雪

炉甘石是白色粉末——**画成一层薄薄的初雪**，既准确，又让"一床的灾难"符合温暖治愈的调子。
不这样处理，画面会脏、会压抑，和"治愈"的基调打架。

**所以五条提示词都要带这一句**：

```
白色粉末画成一层薄薄的初雪，干净柔和，不要脏乱、不要污渍感；
```

### 情绪线

```
停在门口（懵住）→ 背对房间坐着（克制）→ 蹲下平视（交出去）
→ 累着还在擦（她）→ 并肩留一段距离（放手）
```

### 本篇独有的三条禁忌

1. **别画脏乱。** 用初雪，不用污渍。（见上）
2. **别画妈妈发火。** 全篇没有一处愤怒的画面——最激烈的那一下也是"停住"和"背过身"。
3. **最后一张不能画拥抱、不能画牵手。** 要画出**中间隔着一小段自然的距离**——
   那是"放手"的全部意思。拥抱会把它读成"和解"，方向就反了。

## 八、实例三：柿子树那篇

**文章**：《朋友说"你们小区有柿子树好厉害"，我愣了一下》（定稿，2026-10-15）

### ★ 核心视觉策略：把"看惯"画成"没有人抬头"

全篇的题目是"习惯把一切推平"——这是个没法直接画的抽象概念。转译办法：

**树永远在画面里，人总是在低头；只有最后一张，有人停住、抬头。**

配套三条：① 柿子统一画成**暖橘色的小圆果，像一盏盏小灯笼**（全篇暖光的来源）；② **一片叶子都不能画成枯黄萧瑟**——
落也要落在暖光里；③ 每个行人都是**剪影或背影，一律没有抬头**（除了最后一张）。

### 情绪线

```
静止的日常（视而不见）→ 愣住（被一句话点醒）→ 安静的错过（它退成背景）→ 重新看见（温暖踏实）
```

1. **别画成国画写意。** 柿子极易跑成水墨柿子/年画风——风格前缀里的"日系绘本、铅笔淡描边"要顶住，
   出图后先看这条；跑偏就重出，不要将就。
2. **别画萧瑟。** 不要灰蓝天、不要枯枝寒鸦、不要满地残叶；本篇的落点是"重新看见的美好"，冷调会读成悲秋。

## 九、实例四：那晚我本想抱一下我妈

**文章**：《那晚我本想抱一下我妈，最后还是各自睡了》（定稿，2026-10-22）
**规格**：封面 21:9（**图内不加字、不留白**）；插图 4:3，每节一张（5 张）。§二 风格前缀、§三 负面词照用。

### ★ 核心视觉策略：白天有接触，夜里没有

全篇的题眼是"说得出"与"说不出"。所以给一组可以一眼看懂的视觉规则：

- **前四张（白天的甜）里，两个人之间总有接触**：亲、贴额头、捧碗、同坐一条床边。
- **夜里那张必须没有接触**：两个人各自盖一床被子，中间留出一道缝——那道缝就是"没好意思"，是这篇最值钱的画面。
- 人物一律**剪影或侧背影**，不画清晰五官；读者把自己的脸填进去，这是本篇共鸣的来源。

### 情绪线

```
烦躁又柔软 → 甜（被夸懵）→ 暖（粥的热气）→ 安静发凉（听见呼噜）→ 回望温柔（照片）
```

### 本篇独有的四条禁忌

1. **夜里那张别画拥抱、别画牵手。** 一有接触，"没抱"就读不出来了。
2. **别画哭，别画眼泪。** 全篇没有一场哭，情绪靠姿势、距离和光。
3. **别画成三代同堂的全家福。** 每张最多三个人，且总有一人不在画面中心：封面是外婆在门边，插图里是女儿或照片。
4. **别给"兆"配任何数字或文字**，AI 写出来一定是错字。
