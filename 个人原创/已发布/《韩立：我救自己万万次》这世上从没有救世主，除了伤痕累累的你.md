# 《韩立：我救自己万万次》这世上从没有救世主，除了伤痕累累的你

看了那么多修仙动漫，我从没想过自己会因为一段混剪视频，在深夜热泪盈眶。

视频里的韩立，没有法术打斗的炫酷，没有碾压敌人的无敌潇洒。

有的只是他这一路走来，各种受伤、濒死，被打落尘埃，又一次次咬紧牙关爬起来的狼狈画面。

视频标题只有九个字——

《韩立：我救自己万万次》。

看完我久久不能平静。是了，这才是韩立能从无数爽文男主中脱颖而出的真正原因——

**他从来不是什么英雄，只是一个在绝境里死不认命的普通人。**



# 01

# 视频里的狼狈，才是凡人主角的真相

# 

作为一个修仙动漫爱好者，我看过市面上几乎所有同类作品。但只有《凡人修仙传》的韩立，给我留下的印象最深。

他出身偏远山村，长相平平，资质平平，没有可依靠的家族背景。

没有天降的血海深仇，没有拯救众生的伟大志向，也没有嫉恶如仇的英雄情怀。

他不是天生英雄，反而很像我们生活中无处不在的普通人。

在弱肉强食的世界中无可依仗，只能自己咬紧牙关，默默成长，最终一步步攀上了修仙者的金字塔尖。

**我们喜欢他，是因为我们在他身上看到了自己，也看到了那些同样艰难前行的凡人众生的影子。**



弹幕里总有人刷'韩跑跑''韩怂怂'，觉得他太苟了。但你们是不是忘了——

**我们和他是不对等的。**



我们看动漫，知道他是主角，无论何等危局，定能逢凶化吉。

但他自己不知道啊！

对他来说，每一次生死危机，都是拿命去搏一个微茫的可能。

他不敢赌，不敢输，因为没有再来一次的机会。

他的成功，当然有小绿瓶的帮助，**但最重要的是：他从未期待过别人的拯救。**



无论怎样的极端环境，他从不听天由命，只是逼自己冷静，想尽办法用有限的资源扭转局势，一次次从十死无生的绝境中救下自己。

**说到底，凡人无数，谁能成为主角，全看自己。**



# 02

# 撕碎“拯救者妄想”，不做人生的旁观者



仔细想想，修仙世界的危机四伏、险象环生，不就是我们现实生活的具象化吗？

我们**大多数人走不出来，往往是因为陷入了“拯救者妄想”：**



工作受挫时，潜意识里等一个识人的伯乐；

生活一团糟时，幻想出现一个完美的伴侣拯救自己于水火；

甚至在低谷里，寄希望于某种突如其来的转机或好运气……

**我们总在等一个人，带我们脱离苦海。**



但真相是残酷的：

只要你等待被拯救，就相当于把自己人生的主动权交到了别人手里，最后只会变得软弱可欺，失去所有选择。

想要成为自己剧本的主角，我们就必须像韩立一样，自己救自己。

**这世上从没有救世主，能把我们拉出泥潭的，永远只有那个伤痕累累、却依然死死握紧拳头的我们自己。**



从韩立身上，我发现了普通人可以修炼的**“三阶自救功法”**，诸位道友，不妨一起参详一二：



# 03

# 普通人的三阶自救功法：从接纳底色到死不认命



**第一阶｜认清现实：接纳凡人底色，放下“天命妄想”**



韩立结婴时，曾遭遇心魔拷问，最后一问直击灵魂：

“你只是个平凡的山村小子，能活到今天，都是因为小绿瓶。没了它，你什么都不是。”

这一问极其凶险。

韩立的前进之路，小绿瓶的确居功至伟，他也一直把它当作最重要的法宝。

如果掉进了心魔的语言圈套，把一切归结为倚靠外物，他就会失去自我的主体性，道心破碎。

但他沉下心来，认真回溯了自己一路走来的全部历程，最终完成了自我的接纳与确认：

他承认自己起点很低，但也看清了，这条路从头到尾都是他自己的选择。

小绿瓶是加速器，让他走得更快，但就算没有小绿瓶，他也会坚决地走下去。

**他最大的依仗，从来不是外物，而是他自己的心。**



我们破除妄想的第一步，就是放下“凭什么是我”的怨怼，全然接纳真实的自己——

接纳自己平凡的出身、有限的资源和当下的窘迫。

清醒地认清现实，是不再依赖他人的开始。



**第二阶｜心志如铁：认准一条长路，绝不被诱惑绊住**



韩立的修仙路上，其实有很多可以停下的契机。

比如他离开七玄门、拿到墨府解药的时候，如果留下来，就可以继承巨额的财产，还有佳人的真心爱慕。

**但他没有停下，没有被短期的诱惑、他人的评价、虚妄的道德绑架所左右。**



自从确定了长生大道的目标，他就再不曾动摇。

作为一个凡人，他当然知道路途漫漫、千难万难，但他更相信，只要继续走下去，总有机会到达。

**目标远大，但不畏其远大；不好高骛远，不眼高手低。**



**他将所有精力都用于增强自身实力。永远务实地着眼当下，思考下一步该做什么，然后坚决去执行。**





**第三阶｜死不认命：哪怕清零重来，也绝不花时间内耗**



对韩立来说，每一点修为都来之不易，浸透着他的血与汗。

但命运多舛，每次好不容易修到一定境界，就会遭遇意外被打落尘埃，实力暴跌。

后期，他甚至失去了全部修为，神魂重创失忆，还失去了除小绿瓶外的所有法宝。

这就像一个白手起家的创业者，历经千难万险才积攒了一定的财富，一夕之间全部清零，还背上了巨额债务。

现实中遭受这种打击的人，不少从此萎靡不振，再也无法东山再起。

而韩立遭遇这样的打击不止一次，他是怎么做的？

境界跌落——没死就好，大不了重头再修；

被人暗算身受重伤——先躲起来，实力上来了再报仇。

**他从不花时间内耗“为什么命运对我如此不公”。**



**面对命运的折磨，他就像一颗打不扁、锤不烂的铜豌豆。**



**生活给什么牌，他就打什么牌。牌再烂，也想方设法拼尽全力赢下这一局。**



# 04

# 现实里的“韩立”们：用血肉之躯，写下自救的剧本

# 

如果说韩立是虚构世界里的自救者，那么现实生活中，也有人用血肉之躯写下了同样的剧本。

**就像史铁生。**



21岁最意气风发时双腿瘫痪，永远困在了轮椅上。又患上尿毒症，每周透析三次，全身血液抽干清洗。

这种肉体与命运的灭顶之灾，没有任何人、任何亲朋和贵人能拯救，能替他承担哪怕一分一秒。

无数次与死神对峙后，他终于想通了生死与生命的意义。决定自救。

**他接纳了这副残破的躯壳，接纳了人生的局限。**



在无数个寂静黑夜里，他把笔当作武器，救了自己万万次，也点燃了无数和他一样突遭不幸之人的精神之火。

**还有董明珠。**



30岁时，丈夫突然病逝，留下幼子和债务。作为一个普通女性，她的生活瞬间天崩地裂。

但她没有选择再找个男人依靠，或等待命运的垂青，而是孤身南下，从格力最底层的销售员做起。

面对刁难、委屈、被断货的绝境，她从不抱怨“为什么是我”，而是展现出极致的执行力，一路杀成商界铁娘子。

**她没等谁。她自己就是那个贵人。**



# 05

# 握紧拳头，成为你人生剧本真正的主角



韩立，史铁生，董明珠，都在向我们证明：**自助者，天才会助；自救者，天才会救。**



网上有句话很适合我等凡人：**“铮铮劲草，绝不动摇，我救自己千千万万次。”**

纵然生活总有急风骤雨，不要怕，做那铮铮劲草，不服输，不动摇，活下去，与命运勇敢的搏一搏。

请始终记得：“凡人修仙”的路上，没有天降的救世主。

无论你此刻正经历怎样的绝境，不要等待，**救自己！**

**像韩立一样，清醒，决绝，行动。**

**一起把命运死死握在自己手中，成为这场“凡人修仙”里，真正的主角。**
