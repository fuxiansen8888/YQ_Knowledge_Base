# 专注力UP！一个改变让‘黏人精’独立玩了1小时

今天带七七在外面玩时，下了阵小雨。



雨后，滑梯和跷跷板湿了，地面和花坛的泥土也和雨水混在一起，变得脏兮兮的，但不影响小家伙的兴致。



她用小铲子挖泥巴；把捡来的树枝和石子放到泥坑里，假装在炒菜；拿着落叶在满是泥土的花坛上蹭来蹭去；用手抓着湿泥巴来回倒腾……



我多次想阻止她，让她别这么玩，会把身上弄脏。但转念一想，脏了就脏了，对孩子来说，有什么比此刻的快乐更重要呢。

于是我忍住了，任她自由玩耍，只在离她不远不近的地方关注她的安全。



没想到，她玩的比任何一次都更开心，更专注，甚至拒绝我的加入。只偶尔抬眼确认我的存在，就继续沉浸其中。



这跟她平时的表现简直判若两娃。



平日里，无论玩什么，在哪儿玩，她都一定要求大人陪伴和参与。当我们有事要忙，让她自己玩会，多数时候她都很不配合，极少数时候能自己玩，也就能玩5，6分钟。



而今天，她自己玩了近一小时！



这显然跟我今天那一转念的改变有直接关系。



我不由开始反思：日常玩耍时，我们是否对她干涉的太多了？尤其是，对衣服的整洁过于执着了？



每次出门，我们都会给她搭配衣服，要保暖舒服，还要整洁美观。在外面玩时，我们总忍不住出言提醒和纠正她：别抓这个，太脏了！别这么玩，会把衣服弄脏的…



似乎出门在外，时刻保持衣服的整洁干净是极其重要的事。



这也许是正确的。因为成人社会有“先敬罗衣再敬人”的规则。但我们从未思考过，对孩子（尤其是10岁前的孩子）来说，时刻保持衣服的整洁真的那么重要吗？



NO\!



儿童发展心理学常常提到，对于学龄前的孩子，这种看似无目的的“脏玩”恰恰是最好的学习。



10岁内的孩子，玩耍本身就是学习，就是成长。



在无拘无束的探索中，他们的感官被充分激活，想象力、创造力和解决问题的能力正在悄然生长。



相较于把衣服弄脏，自由探索和玩耍才是真正重要的事。



而我们是怎么做的呢？



每当她想用自己的方式探索这个世界时，我们总在旁提醒她，纠正她，告诉她不能这样，不能那样。



时间一久，她就会失去自己探索的动力。总想要我们带着她玩，直接给她示范我们期待的正确玩法，这无疑会扼杀她的创造力。



总是被打断的她，也会因为体会不到沉浸其中的快乐，很难长时间投入到某件事中，这对孩子专注力的形成也非常不利。



创造力和专注力对孩子有多重要，想必任何一个父母都很清楚。跟时刻保持衣服的整洁干净相比，这才是真正重要的事。



从今天开始，不要再舍本逐末了。



孩子的衣服没必要时刻保持干净。别再在孩子玩的时候打断她，纠正她，干涉她。



当然，放手并非放任不管。只要不涉及生命安全，我们只需在一旁默默守护，确保她的安全底线，她想怎么玩就怎么玩。



脏了就回家洗，磕了碰了就回来涂药，给足空间，孩子自然会野蛮生长。



很多时候，父母要做的不是修剪，而是守护。
