# 我曾讨厌近代史，直到遇见那群和我一样迷茫的年轻人

《毛选》中有一句话：

“人活着总是要有一点精气神的。
人如果没有了方向，没有了理想和坚持，任何伟大的事业都不可能完成。
一个国家，一个民族，都需要有精气神。”

国庆期间看这句话，格外有感触。

教员说的精气神到底是什么？

我的理解是：一种不服输的倔强，一种坚定向上的力量。

人有了这种力量，就能无惧命运的挫折，生活的风雨，就能在尘埃里，搏出一片洁净晴朗的天地。

国家有了这种力量，就能把天灾人祸变成多难兴邦，把百年沉沦变成国富民强，就能以黑暗为薪，燃起民族复兴的火光。

✎国家的精气神，来自于人民

新中国刚成立时，这种精气神最为昂扬。

立国之战，教员曾说：我们是钢少气多，对面是钢多气少，钢是厉害，但最终还得看人。

后来，我们奇迹般扭转了劣势，非常重要的原因之一，就是这股不服输的气。

换句话说，我们每个中国人的精气神，合起来，就是整个国家的精气神。

因此，我们希望国家繁荣昌盛，完全可以落到实处，那就是——先把自己建设的繁荣昌盛。

看似宏大的目标，落点就在我们自己身上。

这些道理，我也是近两年才想明白的。

✎一部剧，把课本上的名字变成了人

以前，我也很容易被网上一些观点影响，对现实生出很多片面的批判和怨言。

却从没深究过，那些冠冕堂皇的内容，到底是站在谁的立场，也没考虑过，那些数据是否真的客观。

它们说得看似挺有道理，有数据，有情绪。对近代史不甚了解的我，总是不由自主的跟着点头。

但现在看到，我会先问自己一句：这话是谁说的，说给谁听的，有什么目的。

这个方面，我跟几年前的自己判若两人。

而这变化的起源是一部电视剧——《觉醒年代》。

我很爱看历史剧，但唯独不喜欢近代背景的历史剧。

原因很简单，我们的古代史太辉煌灿烂了，典籍华章，封狼居胥，汉唐盛世，万国来朝，谁不向往呢？

可翻开近代史，不是割地就是赔款，不是全军覆没就是不战而逃。

好容易封建王朝退场了，又是军阀割据，民不聊生，整个民族的苦难全都压缩在这一百年里，看的人心里堵得慌。

而那些开创新中国的名字，课本介绍又太过平面。曾经，为了考试，我记住了他们的名字和丰功伟绩，却无法将他们与真实的人，与我相联系。

直到偶然看了这部剧，我才发现，那些光辉的名字，也是一个个真实的普通人。

他们也曾少年意气，也曾怀抱理想却处处碰壁。

也曾经历贫穷，轻视，孤立；病痛，死别，生离。

也曾为前路迷茫而辗转反侧，为追求理想而忍饥挨饿，为同志分歧而痛哭流涕。

丰功伟绩之前，是很长很长时间的灰头土脸，一败涂地。

但他们没有放弃，竟真的在近乎绝境的情况下，带领整个民族走出了一条全新而光辉的路。

这样真实的奇迹，让我对近代史兴趣大起。

✎当年那些问题，都是更难的版本

深入了解之后，我发现，这段历史，对我们每个中国人来说，都是巨大的精神宝藏，尤其是迷茫焦虑的时候。

因为我们目前遇到的所有问题，当年那群年轻人都遇到过，而且都是更难的版本。

我们苦苦思索：自己到底想过什么样的生活。

他们苦苦思索：整个民族怎么才能活下去。

我们的外部环境是：裁员降薪，消费低迷。

他们的外部环境是：虎狼环伺，敌强我弱，随时都有人扑上来，撕咬我们一块血肉。

我们遇到的问题是：没资源，没背景，低起点，怎么才能逆袭？

他们遇到的问题是：山河破碎，一穷二白，内忧外患，怎么才能让人民过上好日子。

这些问题看似截然不同，其实本质都是一样的。

一代代的年轻人，始终在思考和回答的，都是——

未来路在何方？我能做什么？我该怎么做？

前段时间有一句话流传很广：“一代人有一代人的长征。”

时代变了，具体的问题变了，挑战的形式变了，但我们依然在长征的路上，危机与机遇依然并存。

当年的长征，走在路上的人们，并不知道这条路能不能通向胜利，但既然这是目前能做的最好的选择，那就去做，去走，去面对。

如果你也在自己的路上走累了，回头看看他们当年走过的路吧！你总会得到一些鼓舞，一些精神的力量。

家国宏大，而自我微小，但这宏大正是来源于无数微小。

因此，着眼于微，把自己能做的每件具体的事做好，是我们对自己，也是对国家最好的贡献。

我越来越认识到，这一生真正能建设和改变的，只有我自己。

安排好自己的作息，情绪，经营好自己的家庭，事业，养育好自己的孩子。

在“做”上学，在“事”上练，失败也没关系，总好过在原地举步不前。

走下去，我们总会越来越接近理想的自己。
