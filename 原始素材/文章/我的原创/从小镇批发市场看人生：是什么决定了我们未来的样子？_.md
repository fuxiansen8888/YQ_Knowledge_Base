# 从小镇批发市场看人生：是什么决定了我们未来的样子？​

趁着国庆假期，我们回了趟公婆的老家。那是一个依山而建的小镇，河流穿行而过，秀美而宁静。

散步时，先生和婆婆会突然指着某处告诉我，这儿是他的小学，那儿是她以前常逛的集市……记忆被时光发酵后，散发出温暖的味道。

这天，我们逛到一个小商品批发市场。货品拥挤而陈旧，走廊狭窄，光线昏暗，有种被时代遗忘的落寞和沧桑。

婆婆说，她年轻时曾在这摆摊，那时还没有楼房，只有大棚，酷暑寒冬，风吹日晒，挣点辛苦钱。

我知道这段历史，公公婆婆文化水平不高，起点低，但凭着勤劳敢干，风雨共担，后来的日子也是越过越好。我从他们身上学到过不少生活的智慧。

我们正信步闲逛，忽听一声呼唤，原来是碰到了婆婆的老熟人——当年和她同在这里摆摊的摊主居然还有留下的。一番叙旧，又围过来几位旧时同事。

她们站在狭窄的过道上聊着年轻时的事，感叹岁月匆匆，人生无奈，身边堆放着落灰的衣裤鞋袜。阳光从高处斜射进来，照亮了她们的皱纹和白发。

我望着这一幕，望着这个她们坚守了半生的方寸之地，忽然感到一种时间的重量，这重量让人害怕。

近四十年，她们一直在这里摆摊。从桃李年华到霜华染鬓，半生的时间，她们都被圈在这逼仄压抑的批发市场小小的摊位上，如同身处一个看不见的牢笼！

我忍不住想，是谁困住了她们？生活的压力吗？

可她们风华正茂的时候，正是市场经济腾飞之时，若像我公婆一样去大城市闯闯，极有可能找到更好的发展机会。

但她们没有。小镇外的路明明四通八达，却无人选择去走。

或许她们尝试过，终觉不如现成的生意稳当而放弃了。这一放弃，丢失的不只致富的机会，更是人生的无数种可能性。

画地为牢四十年！年轻的她们怎会想到，自己将半生囿于这小小的摊位上，过着日复一日，古井无波的生活，直至垂垂老矣。

时至今日，她们恐怕早已习惯，更无法跳脱出来，看到自己这一生的轨迹已经可以全部预见。

倘若，让年轻的她们预见40年后的今天呢？她们会不会惊出一身冷汗，从此走上另一条也许更艰辛，但一定更丰富的路呢？

我想一定会的。

年轻人最宝贵的，就是面对无数道路，敢于任意选择的蓬勃野蛮的生命力。

可惜，这生命力很容易消失。

作为生在底层的普通人，如果我们没有不断学习思考来提升自己的认知，没有足够勇气突破旧圈层给予的安全感，就会在世事搓磨中逐渐变得无知无觉。被生活的大浪推着走上一条看似风平浪静，却可能让生命悄然干涸之路！

那就是：放弃了自己生命的一切可能，将微小希望寄托在他人或孩子身上。看似活着，实则灵魂早已死去。终局来临时，回望一生，才发现自己从未真正的活过。

相比之下，这次认识的表妹则选择了另一条路。同样出生底层，年纪轻轻进入社会，她在多个城市各个行业不断折腾，摸爬滚打，肆意探索着自己的生命边界。

我不知她最后会不会成功，但无论结果如何，她永远不会为自己没有好好活过而后悔。

生命，是一场早就知道终点的旅行。人生的路千万条，风雪雷电，平湖险川，高山激流，朝阳余晖，都是风景。

我们何不勇敢的走出门去！去探索！去创造！去感受！乘兴而去，尽兴而归！才不枉人间一趟！
