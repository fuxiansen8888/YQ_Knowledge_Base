# 个人写作排版规则

> 本文档约定个人写作的 Markdown 排版规范，便于新文章一键排版时统一风格。  
> 参考范文：《从讨好型到敢亮剑：一个害怕冲突的人，是怎么找到人际关系出口的》

## 一、整体结构

文章由以下部分顺序组成，缺一不可：

1. **主标题**（一级标题）
2. **第一条分隔线**
3. **开篇 / 引言**（无小标题，2～4 段）
4. **正文章节**（多个二级标题 `## 一、二、三…`，每章后可跟三级标题）
5. **结尾段**（最后一节的收束 + 金句）
6. **第二条及后续分隔线**（章节之间、结尾前）
7. **文末落款**（斜体一句收尾）

---

## 二、标题规范

### 2.1 主标题（一级标题）

- 使用一个 `#`，且全文仅有一处一级标题。
- 格式建议：**主标题：副标题或补充说明**（用中文冒号连接）。
- 示例：`# 从讨好型到敢亮剑：一个害怕冲突的人，是怎么找到人际关系出口的`

### 2.2 正文章节标题（二级标题）

- 使用 `##`。
- 格式：**中文数字 + 顿号 + 本节主题**，如：`## 一、一句话，点醒了我对人际关系的理解`。
- 章节编号连续：一、二、三、四、五…

### 2.3 小节标题（三级标题，可选）

- 使用 `###`。
- 用于某一节内的并列要点，如：`### 斗争的勇气`、`### 斗争的能力`。
- 不加「一、二」等编号，保持简短名词或短语。

---

## 三、分隔线使用

- 使用 Markdown 语法：`---`（三个短横线）。
- **必须出现的位置：**
  1. 主标题下方空一行后，第一条 `---`（标题与开篇之间）。
  2. 每个 **二级标题章节**（`## 一、`、`## 二、`…）的 **整节内容结束后**，在下一节 `##` 之前放一条 `---`。
  3. 全文最后一节结束后、文末落款之前，可再放一条 `---`（与范文一致）。
- 分隔线前后各空一行，便于阅读。

---

## 四、开篇 / 引言

- **不设小标题**，直接以问句、场景或共鸣句开头（如「你有没有这样的感觉：」）。
- 2～4 个短段，每段之间空一行。
- 开篇内应包含：
  - 一句 **加粗** 的核心观点或金句（`**...**`）。
  - 一句过渡到正文的话（如「今天想把…写给你」）。
- 开篇结束后，紧跟一条 `---`，再进入 `## 一、…`。

---

## 五、正文段落与强调

- **段落**：段与段之间空一行；段内不空行。
- **强调**：重要结论、金句、关键词使用 **加粗**（`**...**`），不要全段加粗。
- **引用块**：需要单独突出的金句（尤其是名人名言、核心公式）使用引用 + 加粗：
  ```markdown
  > **以斗争求团结，则团结存；以退让求团结，则团结亡。**
  ```
- **列表**：并列要点用 `-` 无序列表；若需强调关键词，可在列表项内使用 `**...**`，例如：
  ```markdown
  - **以前**：害怕冲突 → 一退再退 → …
  - **现在**：依然不喜欢冲突，但明白了——…
  ```

---

## 六、结尾与落款

- 最后一节（如「五、写给和你一样的你」或「四、写在最后」）用 1～2 段收束，并有一句加粗的总结或祝愿。
- 该节结束后，空一行，加 `---`，再空一行。
- **文末落款**：单独一行，用 *斜体*，以「——」引出，语气为共勉、祝愿或点题。  
  格式：`*—— 与每一个曾经一退再退、却依然想好好活关系的你，共勉。*`  
  或：`*—— 愿我们都能手上有剑，该亮剑时敢亮剑。*`

---

## 七、标点与排版细节

- 使用 **中文标点**（，。；：！？""''）。
- 中文与英文、数字之间可不必加空格（按个人习惯，全文统一即可）。
- 段落首行不缩进（Markdown 惯例）。
- 若引用对话或书名，使用中文书名号《》或引号「」。
- 省略号统一用 `…`（半角三点）或 `……`（六点），全文一致。

---

## 八、检查清单（排版时自检）

- [ ] 全文只有一个一级标题 `#`，且为主标题。
- [ ] 主标题后、每个 `##` 章节结束后、结尾落款前，`---` 位置正确且前后空行。
- [ ] 二级标题为「一、」「二、」…连续编号。
- [ ] 开篇无小标题，且有加粗金句 + 过渡句。
- [ ] 重要结论与金句已加粗或引用块。
- [ ] 文末为单独一行斜体落款，以「——」开头。
- [ ] 段落间空一行，无多余空行（如连续两行空白）。

---

*—— 之后新文章可要求按本《排版规则》进行一键排版。*
