# 备份/ —— 修改知识笔记前的备份

**规则**：修改 `知识/` 下已有笔记，或修改 `个人原创/已发布/` 下的正文之前，
先把原文件复制到 `备份/<YYYY-MM-DD>/<原文件所在层的相对路径>`。

```
备份/2026-09-21/知识/标题模式/自媒体文章起标题技巧.md
备份/2026-09-27/个人原创/已发布/太好了，我才35岁！｜写在35岁生日.md
```

**为什么不用 git 代替**：git 能回滚，但看不出「这次改了什么、为什么改」。
`备份/` 是给人看的快照，两者互补。

**不需要备份的情况**：

- 新建文件（没有原内容可丢）
- `原始素材/` 下的任何文件（本来就不改）
- `工具/公众号数据/` 下的脚本产物（可重新运行生成）
