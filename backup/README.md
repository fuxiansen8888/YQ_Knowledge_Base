# backup/ —— 修改 Wiki 笔记前的备份

**规则**：修改 `wiki/` 下已有笔记之前，先把原文件复制到
`backup/<YYYY-MM-DD>/<wiki 下的相对路径>`。

```
backup/2026-09-21/wiki/titles/自媒体文章起标题技巧.md
```

**为什么不用 git 代替**：git 能回滚，但看不出「这次改了什么、为什么改」。
`backup/` 是给人看的快照，两者互补。

**不需要备份的情况**：

- 新建文件（没有原内容可丢）
- `raw/` 下的任何文件（本来就不改）
- `tools/wechat-data/` 下的脚本产物（可重新运行生成）
